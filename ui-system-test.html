弹窗组件与按钮组件的正确配合使用示例

🔍 弹窗类型 + 按钮组合规范

确认弹窗 (Confirmation)

用于删除确认、重要决策确认
按钮组合模式:
线型按钮-8px（取消）+ 主按钮-8px（确认）
圆角一致性：两个按钮都使用 8px 圆角

表单弹窗 (Form)

用于数据录入、设置配置、个人化设置
按钮组合模式:
线型按钮-12px（取消）+ 主按钮-12px（提交）
圆角一致性：两个按钮都使用 12px 圆角

通知弹窗 (Notification)

用于系统通知、功能更新、促销信息
按钮组合模式:
弱按钮-12px（关闭）+ 强引导按钮-12px（主要操作）
圆角一致性：两个按钮都使用 12px 圆角

预览弹窗 (Preview)

用于图片预览、内容预览、详细信息查看
按钮组合模式:
弱按钮-12px（关闭）+ 主按钮-12px（可选的主要操作）
圆角一致性：两个按钮都使用 12px 圆角

设置弹窗 (Settings)

用于系统配置、偏好设置、复杂表单
按钮组合模式:
线型按钮-12px（取消）+ 主按钮-12px（保存）
圆角一致性：两个按钮都使用 12px 圆角

功能引导弹窗

用于新用户引导、功能介绍
按钮组合模式:
线型按钮-12px（跳过）+ 强引导按钮-12px（继续）
圆角一致性：两个按钮都使用 12px 圆角
